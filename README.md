# Collabiste

Page d'accueil simple pour le projet **Collabiste**, réalisée en HTML et CSS.

## Contenu

- `index.html` : structure et texte de la page d'accueil.
- `style.css` : styles de la page.

## Lancer le projet

Aucune installation ni dépendance n'est nécessaire. Ouvrez `index.html` dans un navigateur web.

## Personnalisation

Modifiez le contenu de `index.html` pour changer le texte de la page et `style.css` pour ajuster son apparence.
